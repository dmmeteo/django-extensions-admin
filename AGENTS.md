# Project direction

Before planning, changing the roadmap, designing APIs, implementing or reviewing changes, read [PHILOSOPHY.md](PHILOSOPHY.md). It is the accepted product direction. Include its short **Philosophy fit** check in plans and implementation packets. Surface conflicts for an explicit product decision rather than silently weakening a principle.

Use README for usage and limitations and ROADMAP for candidates; neither overrides PHILOSOPHY.md. Keep principles in that single source, not copied into agent instructions.
