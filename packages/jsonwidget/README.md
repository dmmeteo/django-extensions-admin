# django-extensions-admin-jsonwidget

A native-looking JSON editor and read-only rendering for models.JSONField in the Django admin.

This is one feature of [django-extensions-admin](https://github.com/dmmeteo/django-extensions-admin). Install it through the main
distribution's extra, which keeps every feature you did not choose off your system:

```bash
pip install "django-extensions-admin[jsonwidget]"
```

Usage, settings and removal: [JSON widget](https://github.com/dmmeteo/django-extensions-admin/blob/main/docs/json-widget.md).

> **Release status.** Version 0.1.0 is **not yet published on PyPI**. Until it is, build
> the wheels from a checkout as [the installation page](https://github.com/dmmeteo/django-extensions-admin/blob/main/docs/installation.md) shows.
