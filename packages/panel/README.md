# django-extensions-admin-panel

The shared, resizable side panel that admin tools such as the REPL open in.

This is one feature of [django-extensions-admin](https://github.com/dmmeteo/django-extensions-admin). It does nothing on its own.
The tools that open in it install it, so you get it through their extra:

```bash
pip install "django-extensions-admin[repl]"
```

Usage, settings and removal: [Tools panel](https://github.com/dmmeteo/django-extensions-admin/blob/main/docs/panel.md).

> the wheels from a checkout as [the installation page](https://github.com/dmmeteo/django-extensions-admin/blob/main/docs/installation.md) shows.
